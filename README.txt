MAT 189 starter folder ~ this is Larry's portfolio. Make it yours.

What is in here:

  MAT189/
    portfolio/
      index.html   <- the page. open it in your BROWSER to see it.
                      open it in a PLAIN TEXT editor to change it.
      style.css    <- the look. do not touch it today.
      media/       <- Larry's files. yours go here too,
                      named projectname_NN.ext ~ lowercase, no spaces.

What to do:

1. Double-click index.html ~ meet Larry's portfolio.
2. Copy YOUR media files (from Homework 1) into media/.
3. In the text editor, swap Larry's content for yours, one project at
   a time: filename, title, meta line, caption, abstract.
   Save. Reload the browser. Every time.
4. Delete Larry's leftover sections and his media files when done.
5. When it renders with ALL your projects: zip this whole MAT189
   folder as lastname_MAT189.zip and upload it to the link Karl
   emailed. Before you leave. Uploaded = credit.

If the page breaks, you changed one character too many. The browser
means exactly what you typed. Look at your last edit.
